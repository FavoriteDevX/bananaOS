## 🚀 How to Run Locally

If you want to run this clone locally on your computer for development:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate into the folder:**
   ```bash
   cd banana-os
   ```
3. **Open the system:**
   Simply double-click the `index.html` file to boot it up in your favorite web browser! Or run a local server:
   ```bash
   # If you use VS Code, install "Live Server" extension, or run:
   npx serve .
   ```
